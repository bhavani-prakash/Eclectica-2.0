Dedicated Form Links & Vercel Deployment

1
How to edit your Google Form links in the code:

Open website-3-neon-matrix/src/data/eventsData.js (lines 7–16).
Each event has its own link:
"tech-quiz": "https://docs.google.com/forms/d/e/.../viewform",
"layotrix": "https://docs.google.com/forms/d/e/.../viewform",
Simply paste your real Google Form URL for each event.

2
Deploying to Vercel:

Each folder already contains a pre-configured vercel.json.
• Method A (CLI): cd website-3-neon-matrix and run vercel.
• Method B (GitHub & Vercel Dashboard): Push the repository to GitHub, go to vercel.com/new, import the repo, and set the Root Directory to website-3-neon-matrix (or whichever theme you choose).
